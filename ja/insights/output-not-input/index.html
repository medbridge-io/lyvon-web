入学準備

インプットではなくアウトプット：医学英語がスピーキングのスキルである理由

2026年11月 · 入学準備

科学を学ぶ学生は大勢います。しかし、それを英語で自信を持って説明できる学生はわずかです。そのギャップこそが、多くの口頭入試の合否を分けるところです。

知識は、説明と同じではない

従来の対策は、暗記、読解、問題演習といったインプットに集中しています。しかし医学部の面接、アカデミックな議論、研究発表、そしてその先の臨床現場で求められるのはアウトプットです。考えを整理し、英語で明確に表現し、リアルタイムで自信を持って伝える力です。

解糖系のすべてのステップを知っている学生でも、試験官に「なぜ細胞にはそれが必要なのですか？」⁠と問われた瞬間に固まってしまうことがあります。知識はあるのです。足りないのは、それを言葉にするための構成です。

声に出して使う2つのフレームワーク

MedBridge では、2つのシンプルな構成を、自然に使えるようになるまで練習します：

  • PREP：意見・経験を問う質問に。Point → Reason → Example → Point。
  • D · E · E：概念を問う質問に。Definition → Explanation → Example。

MedPath では、同じ50の生物・化学レッスンを、3つのレベルで深めていきます：Define、Explain、Justify。トピックは同じまま、変わるのは質問の深さだけです。口頭試験のように、追加の質問を受けても答えを論理的に守れるようになるまで続けます。

すべてのセッションは記録で終わる

1対1のセッションごとに、講師が LLR（Lesson Learned Report）⁠を作成します。授業中は簡潔なフィードバックを行い、詳しい添削は LLR にまとめるため、エラーパターンを時間をかけて追跡し、修正することができます。すべての回答は、発音、流暢さ、語彙、デリバリーの4つの基準で評価されます。

なぜ身につき続けるのか

試験のために暗記した英語は、やがて薄れていきます。しかし、考え、自分を表現する力は、医学部でも、研究でも、そして医療のキャリアを通じて、ずっとあなたとともにあります。それが LYVON という名前に込めた思い、Live On です。
