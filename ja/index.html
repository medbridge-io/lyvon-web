02 — LYVON メソッド

家庭教師ではなく、システムを。

LYVON は出願代行業者ではありません。代行業者は出願手続きを扱い、私たちは試験に合格する力を育てます。設計され、記録され、測定されるメソッドで、セッションを重ねるごとに。

成長の証拠

感覚ではなく、記録で。

毎回のセッション後、講師が5つの領域にわたる Lesson Learned Report（LLR）⁠を発行します。レポートは蓄積され、プログラム総括レポートにまとめられます。解決できたこと、残っている課題、そして次に取り組むことがわかります。

  • 進捗 · スピーキング · リスニング · 語彙 · 添削
  • 1⁠〜⁠2週間ごとにエラーパターンを追跡
  • 4セッションごとに詳細なフィードバック

実際の LYVON プログラム総括レポートを、受講生の同意を得て転載しています。氏名は匿名化しています。

03 — よくあるご質問

よくあるご質問。

料金がサイトに載っていないのはなぜですか？

料金は開始段階と週あたりの回数によって異なります。無料レッスンのあと、診断レポートとあわせて、おすすめのプランと正確な料金をご案内します。お申し込みの義務はありません。

レッスンはどのように行いますか？

Zoomによるライブの1対1オンラインレッスンで、1回50分、週2〜4回です。曜日と時間はご自身で選べます。

誰が教えますか？

LYVONメソッドの研修を受けた、パートナー企業StepForward（フィリピン）⁠のプロの英語講師が担当します。レッスンは英語で行い、受講生・ご家族とのやり取りはLYVONが日本語・韓国語・英語で直接行います。

レッスンができる時間帯は？

平日9:00〜22:50、週末9:00〜17:50（日本・韓国時間）⁠です。台湾・香港では1時間早い時刻になります。

試験まで6か月を切っていますが、間に合いますか？

必ずしも遅くはありません。無料診断のあと、試験日と重要トピックに合わせた短期プランを作成します。

レッスンの日程は変更できますか？

はい。レッスンの24時間前までにご連絡ください。詳しくは利用規約をご覧ください。

出願手続きの代行もしていますか？

いいえ。LYVONは英語教育のみを提供しており、入学手続きの代行は行わず、合格を保証するものではありません。

05 — 私たちの理念

アジアをつなぎ、国境を越えて学ぶ。

LYVON は、意義ある機会が地理的な条件によって制限されるべきではないと考えています。志ある一人ひとりに、国境を越えて教育やキャリアを追求するために必要な知識・準備・サポートを届けます。

鍛えるのはインプットではなく、アウトプット。

多くの学生がつまずくのは、知識が足りないからではありません。知っていることを、英語で、質問を受けながら説明できないからです。LYVON は、その力を一人ひとりに合わせて鍛えます。

06 — 事業内容

新たな可能性をひらく教育。

01

医学教育

医学部入試の準備から入学後まで、段階ごとのプログラム。

MedPath — ヨーロッパ医学部の入試・口頭試験 MedBridge — 医学英語の基礎 MedConnect — 入学後のメンバーシップ（パイロット） 
02

語学・アカデミック基礎

緊張する場面でも話を組み立てられる方法です。決まった型で答え、段階を追って説明し、追加質問にも論理を保ちます。

  • PREP — 意見を問う質問：Point → Reason → Example → Point
  • D·E·E — 概念を問う質問：Definition → Explanation → Example
  • Define → Explain → Justify — 同じ内容を3段階の深さで
  • AI + 講師 — 講師による1対1指導に加え、AIレッスン音声で予習・リスニング。AI学習ツールも順次追加予定
  • LLR — 毎回のレポートでエラーパターンを修正

07 — ネットワーク

3つの都市、ひとつのビジョン。

LYVON は3つの都市で活動しています。それぞれの都市が、プログラムづくり、受講生のサポート、そしてアジアでの成長において、異なる役割を担っています。

SEOUL

事業の基盤

LYVON の本拠地。受講生・ご家族との関係を築き、韓国市場を開拓しています。

TOKYO

戦略と展開

国際戦略とブランドの方向性、日本市場の開拓、そして将来の日本キャリアプログラムに向けた基盤づくりを担っています。

MANILA

アカデミック運営パートナーシップ

フィリピンの独立した教育運営パートナーである StepForward と協働し、アカデミック運営を行っています。

StepForward は独立した組織であり、LYVON が所有する組織でも、LYVON の子会社でもありません。
